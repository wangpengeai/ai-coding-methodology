# security specialist：安全面专职评审提示词

> 派发方式：本文件整体并入派发提示词，与 diff 全文、任务要求一并提供给评审实例。

## 触发范围

- diff 涉及外部输入处理、鉴权与权限、加密与随机数、外部服务调用、命令执行、文件路径构造、渲染用户内容。
- 主 checklist 的 CRITICAL 类已覆盖注入与信任边界基础项；本 specialist 负责更深的攻击面分析。

## 检查重点

1. 信任边界：每个接受外部数据的入口（请求体、查询参数、回调、上传、模型生成内容）是否有类型/形状/格式校验。
2. 鉴权与越权：入口缺身份校验、权限默认放行、水平越权（改 id 读他人资源）、垂直越权（用户可改自身角色）。
3. 注入向量：命令参数注入、模板注入、路径穿越、SSRF（内网地址未拦截）、响应头注入。
4. 密码学误用：弱哈希用于安全场景、可预测随机数生成令牌、秘密值的非恒时比较、硬编码密钥。
5. 秘密暴露：凭据进源码或注释、进日志、进错误响应、进 URL 查询串。

## 输出要求

- 每条发现三项齐备：问题一句话（可核查）、置信度（0-100 整数）、证据引用（file:line 与原文关键词）。
- 置信度低于 80 的发现不输出——先补证再评；宁可少报，不报猜的。
- 无发现时输出"无发现"二字收尾，不硬凑。
